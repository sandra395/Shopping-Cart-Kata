# Shopping Cart

This is a simple shopping cart project made with C# and .NET.

This project allows users to add products, count items and calculate the total price.

## Features

- Adds products to a cart.
- Counts how many items are in the cart.
- Calculates the total price in pence.
- Returns 0 items and 0 pence for an empty cart.

**Not completed:** The 10% discount for buying more than one of the same product (requirement 4) is not included.

## Project files

- `Product.cs` — Stores a product's details such as a code, name, and price.
- `Cart.cs` — Adds products, counts items, and calculates the total.
- `Program.cs` — Runs the shopping cart example.
- `ShoppingCart.Tests/UnitTest1.cs` — Contains unit tests using xUnit.

## How to run

- You need the .NET SDK.
- Download or clone this project from GitHub.
- Open the terminal in the `ShoppingCart` folder.
- Run the following command to start the application:
  ```bash
  dotnet run

  To run the unit tests, use:
  dotnet test ShoppingCart.Tests/ShoppingCart.Tests.csproj
